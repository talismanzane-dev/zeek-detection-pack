# pcaps/

Drop packet captures (`*.pcap`, `*.pcapng`) here for the Docker lab. Captures
are git-ignored — never commit production traffic.

`make lab-demo` writes `zdp-demo.pcap`, a deterministic synthetic capture
generated by `tools/gen_demo_pcap.py` (C2 beacon, DNS tunnel, DGA burst,
PsExec-style admin-share staging, benign web/DNS), so a first run produces
detections without any external data.
